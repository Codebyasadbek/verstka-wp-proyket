# ООО «Эксперт канатной резки» — верстка (HTML / CSS / JS)

Статическая верстка посадочной страницы по утверждённому дизайн-макету и ТЗ.
Это первый этап: чистая верстка на HTML/CSS/JS. На следующем этапе блоки
подключаются к WordPress + ACF (все тексты, карточки, фото и контакты станут
редактируемыми из админки).

## Структура

```
index.html              — главная страница (все блоки)
privacy-policy.html     — Политика конфиденциальности
consent.html            — Согласие на обработку персональных данных
robots.txt              — правила индексации
sitemap.xml             — карта сайта
css/
  style.css             — основные стили + адаптив
  legal.css             — стили юридических страниц
js/
  main.js               — бургер-меню, плавный скролл, модальная форма
                          (маска телефона, валидация, honeypot), галерея,
                          lightbox (стрелки / Esc / свайп), кнопка «наверх»
assets/
  icons/                — SVG-иконки (тёмный контур) для светлых блоков
  icons-dark/           — SVG-иконки (жёлтые) для тёмных блоков
  img/                  — фото (герой, технологии, галерея)
  logo/                 — логотип и favicon
```

## Реализованные блоки (по ТЗ)

1. Шапка (sticky) + бургер-меню
2. Первый экран с диагональной тёмной панелью
3. Блок ключевых цифр
4. Виды работ и сфера применения (инженерная схема)
5. Наши преимущества (13 пунктов, тёмный блок)
6. Технологии (4 карточки)
7. Фото процесса работы (лента + lightbox)
8. Объекты (карта России + 14 карточек)
9. Контакты
10. Подвал + кнопка «наверх»
11. Модальная форма заявки

## Адаптивность

Проверено без горизонтального скролла на ширинах:
1920 / 1440 / 1200 / 1024 / 768 / 480 / 360 px.

## Что подключается на этапе WordPress

- Отправка заявок на email администратора и дублирование в Telegram
- reCAPTCHA (сейчас реализован honeypot на стороне клиента)
- Вывод всех текстов/карточек/фото через ACF
- SEO-плагин (Rank Math / Yoast), Schema.org уже размечена в разметке
