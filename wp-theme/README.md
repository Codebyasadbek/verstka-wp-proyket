# WordPress тема «Rezka Expert»

Готовая тема для WordPress: вся вёрстка перенесена в PHP и подключена к ACF.
Всё содержимое (тексты, фото, карточки, контакты) редактируется из админки.

## Установка (2 минуты)

1. **Установите плагин ACF:**
   Плагины → Добавить новый → найдите **Advanced Custom Fields** → Установить → Активировать.

2. **Загрузите тему:**
   Внешний вид → Темы → Добавить новую → **Загрузить тему** →
   выберите файл `rezka-expert.zip` → Установить → **Активировать**.

3. **Сделайте страницу главной (важно для ACF-настроек):**
   Ничего создавать не нужно — тема сама показывает содержимое по умолчанию.
   Поля появятся в меню админки как **«Контент сайта»**.

4. **Редактируйте содержимое:**
   В админке слева → **Контент сайта** → вкладки:
   Контакты, Первый экран, Цифры, Виды работ, Преимущества, Технологии,
   Галерея, Объекты, Блок «Свяжитесь».
   Пока поля пустые — на сайте показывается контент по умолчанию (как в макете).

## Что уже работает

- Все блоки главной страницы (как в макете, 1:1)
- Шрифты Montserrat/Inter — локальные (не зависят от Google)
- Меню, бургер, галерея с lightbox, кнопка «наверх»
- Модальная форма (маска телефона, валидация, honeypot)
- Контакты берутся из одного места и подставляются в шапку, футер и блок контактов

## Что подключается отдельно (следующий шаг)

- **Форма → email/Telegram:** установить Contact Form 7, создать форму и
  вставить её шорткод в `footer.php` вместо HTML-формы (место отмечено комментарием).
- **SEO:** установить Rank Math SEO (Title/Description/sitemap/schema).
- **Политика конфиденциальности:** Настройки → Конфиденциальность → выбрать страницу
  (ссылка в футере и форме подтянется автоматически).

## Структура темы

```
rezka-expert/
  style.css            — заголовок темы
  functions.php        — подключение стилей/скриптов, хелперы, подключение ACF
  header.php           — <head> + шапка
  footer.php           — подвал + модальная форма + lightbox
  front-page.php       — главная страница (все блоки, данные из ACF)
  index.php            — запасной шаблон
  inc/acf-fields.php   — поля ACF и страница «Контент сайта» (в коде)
  assets/              — css, js, шрифты, иконки, изображения
```
