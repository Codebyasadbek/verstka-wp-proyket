# Rezka Expert design assets

Набор иконок и декоративных SVG/PNG под утверждённый макет сайта ООО «Эксперт канатной резки».

Папки:
- svg/ — основные SVG с тёмно-синим контуром и жёлтыми акцентами
- png_512/ — PNG версии на прозрачном фоне, обрезаны по содержимому
- svg_yellow_for_dark_bg/ — SVG версии для тёмных блоков, жёлтые линии
- png_512_yellow_for_dark_bg/ — PNG версии для тёмных блоков

Палитра:
- Navy: #172432
- Dark: #101A24
- Yellow accent: #F2B91F
- Gray line: #D9DEE5

Фото станков и галерея не включены — только иконки и декоративная графика для верстки блоков.
